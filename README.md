# HealthSync Clinic Management System

A full-stack Clinic Management System built using ReactJS, Node.js, Express, and SQLite.

The application helps clinics manage appointments, patients, prescriptions, billing, and analytics efficiently through a centralized digital platform.

---

# Features

## Authentication & Roles
- Role-based login system
- Admin access
- Doctor access
- Patient access
- Protected routes

## Appointment Management
- Create appointments
- Update appointment status
- Delete appointments
- Prevent doctor double-booking
- Search and filter appointments
- Appointment status tracking

## Patient Records
- Add patient records
- Update patient details
- Delete patient records
- Medical history management

## Prescription Management
- Create prescriptions
- Search prescriptions
- Delete prescriptions
- Doctor workflow management

## Billing System
- Generate invoices
- Revenue tracking
- Payment methods
- Delete billing records

## Analytics Dashboard
- Total appointments
- Total patients
- Total prescriptions
- Revenue analytics
- Charts and statistics
- Recent appointments

## UI/UX
- Professional responsive UI
- Dark mode support
- Sidebar navigation
- Modern dashboard design
